ads-caso-uso-dev

Política de privacidad

Última actualización: 2 de noviembre de 2026

1. Qué es esta aplicación

ads-caso-uso-dev es una herramienta interna de desarrollo, operada por Santiago Mejía Ads, que usa la Marketing API de Meta para crear y administrar campañas publicitarias en cuentas publicitarias y Páginas de Facebook propias del operador. No está dirigida al público ni ofrece inicio de sesión a terceros.

2. Datos que se tratan

La aplicación solo accede a los datos que el propio operador autoriza en Meta:

  • Identificadores y configuración de sus cuentas publicitarias (nombre, moneda, zona horaria, estado).
  • Identificadores y nombre de las Páginas de Facebook que administra.
  • Objetos publicitarios que la aplicación crea: campañas, conjuntos de anuncios, creativos, anuncios e imágenes.
  • El identificador de acceso (token) emitido por Meta para el operador.

La aplicación no recopila datos personales de usuarios finales, no lee mensajes, publicaciones de terceros ni listas de amigos, y no usa cookies ni rastreadores.

3. Para qué se usan

Exclusivamente para crear, consultar y eliminar objetos publicitarios en las cuentas del operador, y para probar integraciones con la Marketing API. Los datos no se venden, no se ceden a terceros y no se usan para perfilar personas.

4. Dónde se guardan y por cuánto tiempo

Los objetos publicitarios residen en los sistemas de Meta. El token de acceso y el secreto de la aplicación se guardan únicamente en el equipo del operador, en un archivo local que no se publica ni se versiona. La aplicación no mantiene una base de datos propia. Los tokens caducan según las reglas de Meta y pueden revocarse en cualquier momento.

5. Seguridad

Todas las llamadas a Meta viajan cifradas por HTTPS, se firman con appsecret_proof y el token se envía en una cabecera, nunca en la URL. Los secretos se ocultan en cualquier registro o mensaje de error.

6. Eliminación de datos

Puedes pedir la eliminación de cualquier dato asociado a esta aplicación siguiendo las instrucciones de eliminación de datos.
